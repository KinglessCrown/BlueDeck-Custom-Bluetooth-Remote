# Changelog

## 1.0.0
- BLE and Classic Bluetooth serial (SPP) connections
- Free-form layout editor: move, resize, add, copy, delete controls
- Control types: Hold, Toggle, Slider, Joystick
- Custom commands with `{v}`, `{x}`, `{y}`, `{a}`, `{m}` placeholders and `hex:` raw bytes
- Per-control colour, text size and corner radius
- Joystick dead zone and invert X/Y
- Settings: line ending, prefix/suffix, UUIDs, write type, packet size, auto-reconnect, heartbeat, send rate, orientation, grid snap
- Monitor with TX/RX log and manual send
- Layout copy/paste backup
- App icon and dark theme
